## ⚡ Key Highlights & Features

### 🌌 1. 3D Spatial Computing & Holographic Meshes
- **Interactive Spatial Core Viewer**: Live Three.js Torus Knot mesh with real-time orbit controls, wireframe toggles, dynamic LOD quality presets, and audio-reactive equalizers.
- **Skill Constellation 3D Sphere**: Interactive particle constellation projecting technical proficiencies into orbit.
- **Ambient Holographic Canvas**: Ambient particle field and background cyber grid with fluid camera motion.

### 🎨 2. Cyber HUD Aesthetic & Dual Theme Matrix
- **State-of-the-Art Design**: Bespoke cut-corner cards (`cut-corner-button`, `cut-corner-14`), sci-fi telemetry overlays, scanning laser effects, and glowing neon backdrops.
- **Dual Matrix Themes**: Instantly toggle between **Cyan Core** (`#00E5FF`) and **Neon Purple Matrix** (`#A855F7`) with zero-FOUC state synchronization.

### 🤖 3. Integrated AI Assistant System
- **Holographic AI Modal**: Real-time interactive AI chat assistant capable of answering questions regarding enterprise project architectures, tech stack, and career background.
- **Floating AI Trigger**: Draggable HUD trigger orb with animated orbital rings and pulse beacons.

### 🔊 4. Web Audio Synthesizer Engine
- **Audio-Feedback FX**: Custom synthesized sound feedback for laser blasts, button clicks, card tilts, success chimes, and section transitions.
- **Master Sound Control**: Quick HUD audio toggle with visual animated frequency bars.

### 📜 5. Interactive 3D Curved Project Showcase & Deep Dives
- **Curved Project Carousel**: 3D perspective slider with spring physics navigation.
- **Full-Spec Detail Pages**: Dedicated routes (`/project/[id]`) featuring mission briefs, full tech breakdowns, engineering challenges, and fullscreen lightbox galleries.

### 👤 6. Operator Biometric Dossier
- High-resolution operator portrait display with holographic scanlines, telemetry matrix, corner coordinate brackets, and live availability indicators.

## 🚀 Getting Started

### 1. Prerequisites
- **Node.js**: `v18.18.0` or higher
- **Package Manager**: `npm` / `yarn` / `pnpm`

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/deepu-paswan-1123/cyber-3d-portfolio.git

# Navigate to project directory
cd cyber-3d-portfolio

# Install dependencies
npm install
```

### 3. Development Server
```bash
# Start local development server with Turbopack
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Production Build
```bash
# Build production bundle
npm run build

# Start production server
npm run start
```
